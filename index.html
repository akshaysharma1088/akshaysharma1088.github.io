Research

Evidence over hype

My research asks practical questions about AI in data systems and answers them with executable benchmarks: does the translated pipeline produce the same data, does the fix leave the tables correct, and when should an agent hand off to a person.

  • Domain-Driven Data and AI Platforms: Governing Analytics and Machine Learning Pipelines at Scale IET Software · 2026 A domain-driven reference architecture for governing analytics and ML pipelines in large enterprises.
  • LEGATO: Agentic Large Language Model Translation of Legacy ETL Workflows to Modern Dataflow Code with Test-Based Semantic Verification Preprint · 2026 An agent that translates legacy ETL into Spark and checks every translation against executable data tests.
  • Fix or Page? Silent Harm and Safe Escalation When LLM Agents Remediate Data Pipeline Incidents Preprint · 2026 64 broken pipelines, three model sizes: data quality monitors approved every harmful fix, while the agents' own confidence was the useful safety signal.
  • When the Rules Collide: Explainability, Fairness, and Model Risk Governance in Credit Machine Learning Preprint · 2026 A review of how fair lending law, model risk guidance and capital rules constrain one another in credit ML.
  • An Event-Driven Medallion Architecture with Domain-Driven Design for Training-Serving Consistent Credit Risk Feature Engineering Preprint · 2026 Event-driven medallion pipelines that keep credit risk features consistent between training and serving.
  • Agent-Oriented Reference Architecture for Domain-Driven Enterprise Data Platforms Preprint · 2026 A reference architecture for running AI agents over domain-owned enterprise data.
  • Domain-Driven Governance for Regulated Lakehouses: A Contract-Based Architecture and Reproducible Evaluation on Snowflake Preprint · 2026 Governance that propagates across domains, measured with a reproducible Snowflake benchmark.
  • Proactive Credit Line Increase Using Risk-Constrained Explainable Machine Learning Preprint · 2026 Credit line decisions as constrained profit maximization, with calibrated models, SHAP explanations and fairness limits. A. Sharma, G. Sharma
  • FraudRAG: Knowledge Graph-Augmented Retrieval for Real-Time Financial Statement Fraud Detection Using a Domain-Driven Medallion Architecture Preprint · 2026 A Graph-RAG pipeline combining a Neo4j knowledge graph and vector retrieval to check financial statements.
  • A Domain-Driven Reference Architecture for Scalable and Governed Data Systems in Regulated Enterprises Preprint · 2026 The reference architecture behind domain-owned, governed data platforms in banking.
  • Risk-Aware FinOps Optimization Using Machine Learning in Regulated Multi-Cloud Environments Under review · IIPEM 2026 Calibrated cost forecasts and tail-risk optimization for cloud spend under data residency rules. G. Sharma, A. Sharma, S. A. Syed
  • Risk-Aware Self-Healing Cloud Infrastructure Using Agentic AI and Policy-Based Remediation for Regulated Financial Systems Under review · ISASF 2026 Agents propose repairs; a deterministic policy gate decides what may run. G. Sharma, A. Sharma, D. Singh
